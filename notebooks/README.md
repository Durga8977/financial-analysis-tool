# Jupyter Notebooks

This directory contains Jupyter notebooks for financial analysis, backtesting, and data exploration.

## Notebooks (Coming Soon)

- `01_portfolio_analysis.ipynb` - Portfolio performance and risk analysis
- `02_price_tracking.ipynb` - Real-time and historical price analysis
- `03_risk_metrics.ipynb` - Calculate Sharpe ratio, volatility, and other metrics
- `04_backtesting.ipynb` - Backtest trading strategies
- `05_asset_allocation.ipynb` - Analyze and visualize asset allocation
- `06_expense_tracking.ipynb` - Budget and expense analysis

## Running Notebooks

```bash
jupyter lab
```

Then navigate to the notebook you want to run.
